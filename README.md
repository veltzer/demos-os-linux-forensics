# demos-os-linux-forensics

Demos and lab material for a Linux forensics course: memory and disk image
analysis, timeline reconstruction, file carving, log correlation, and
persistence hunting, all from the investigator's chair.

`LAB_IDEAS.md` is a scratch list of hands-on lab exercises to draw from.
Each lab is meant to run in a disposable VM or an isolated lab network, on
data the instructor prepared.
